# Single-Page CV - roadmap.sh Project

This project is an implementation of the [Single-Page CV](https://roadmap.sh) challenge from roadmap.sh. The main focus of this project is to build a clean document structure using pure semantic HTML, apply essential SEO meta tags, set up Open Graph tags, and include a custom favicon.

## ✨ Features & Project Requirements
- **Semantic HTML:** Utilizes proper structural elements such as `<header>`, `<main>`, `<section>`, `<article>`, and `<footer>`.
- **SEO Optimization:** Equipped with optimized meta tags for description, author, and page title.
- **Open Graph Ready:** Pre-configured for rich link previews when shared on social media platforms (like LinkedIn or WhatsApp).
- **Favicon:** Custom icon displayed on the browser tab.

## 🛠️ How to Run the Project Locally
1. Clone or download this repository to your local computer.
2. Open the project folder.
3. Open the `index.html` file using your web browser or run it via the *Live Server* extension in VS Code.
